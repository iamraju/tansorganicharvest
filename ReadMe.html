⚙️ Setup & Configuration

Requirements

  • Visual Studio 2022 or later
  • SQL Server Express 2019 or later (or LocalDB)
  • .NET Framework 4.8

Database Setup

  1. Open SQL Server Management Studio (SSMS)
  2. Run the schema script: Database/TansDB_Schema.sql
  3. The connection string in web.config is pre-configured:
    Data Source=localhost\SQLEXPRESS; Initial Catalog=TansDB; Integrated Security=True
  4. If your SQL Server instance name differs, update Data Source in web.config

Running the Application

  1. Open TansOrganicHarvest.sln in Visual Studio
  2. Press F5 or click Start Debugging
  3. The site opens at https://localhost:PORT/
